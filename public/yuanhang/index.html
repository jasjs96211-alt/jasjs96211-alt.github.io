电脑／手机 · 学习与问道云同步

未开启云同步

保留你喜欢的全屏桌面版。两个入口分别登录同一个邮箱并开启同步后，任务、学习和已确认导入的游戏记录会通过云端同步。

页面打开且联网时同步；保存后稍等状态变成「已同步」再退出。桌面版关闭时不会持续运行，重新打开后会拉取更新。当前进行中的专注计时不跨入口同步。

  1. 先在有数据的浏览器版导出一份 JSON 备份。若要先搬数据，可在桌面版用下方「合并另一入口的记录」导入。
  2. 在浏览器版填写邮箱→发送登录邮件→长按邮件里的登录按钮复制链接，粘贴回此页验证→开启自动同步。
  3. 回到原来的全屏桌面版，用同一邮箱再申请一封新邮件，重复验证并开启。登录链接只能用一次，不要把两个入口共用同一封链接。

一次性迁移

主屏幕版和浏览器版各自保存数据。未开启云同步时建议固定使用一个入口；本功能只合并你选中的备份；需要自动同步时，请在上方分别登录同一邮箱。

  1. 在有旧记录的入口，打开「设置」→「导出 JSON 备份」，保存到「文件」。不要删除旧入口或清除数据。
  2. 回到打算长期使用的入口，在这里选择刚才的 JSON，核对预览后确认合并。
  3. 以后从同一浏览器书签进入。若希望桌面一点打开，可新建只有「URL → 打开 URL」的快捷指令，网址为 https://jasjs96211-alt.github.io/yuanhang/，将该快捷指令添加到主屏幕，命名「远航·浏览器」。与游戏自动化保持同一个默认浏览器。
