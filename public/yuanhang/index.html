同步规则

默认先在本地保存。首次登录后请选择「上传本地」或「下载云端」。之后在页面打开且网络可用时自动同步；其他设备修改可能触发冲突，需要你选择保留哪份数据。

⚠️ 两台设备上的记录可能发生冲突。请先导出 JSON 备份，再选择保留本地或云端。不会自动覆盖冲突数据。

⚠️ 云同步需网页托管在 HTTPS（或 localhost）环境；直接双击打开 HTML 文件可继续离线使用，但不建议在 file:// 下连接云服务。提醒通知由 Google 日历或 ChatGPT 定时任务承担，关闭网页后无法保证主动提醒。

如何开始（只需配置一次）

① 建立 Supabase 项目 → ② 复制项目 URL 和公开密钥 → ③ 在 SQL Editor 运行源码包 backend/schema.sql → ④ 将本网页文件部署至 HTTPS → ⑤ 手机和电脑分别用同一邮箱验证码登录。推荐先在当前设备点击「上传本地数据」，再在另一台设备点击「下载云端数据」。正式使用前先导出一次 JSON 备份。

导出数据备份

下载 JSON 文件，包含自定义日程、打卡、学习时间和屏幕时间。建议每周备份；不同手机与电脑之间不会自动同步。

导入已有备份

导入后将覆盖当前浏览器的全部本地记录，请先导出备份。

导出到手机日历

将所有安排导出为 .ics 日历文件，包含提前一天、提前一小时的提醒。需自行导入日历 App，提醒效果以导入平台为准；导出后新增任务不会自动同步。

数据和提醒限制

单机离线工作台；本地数据可能因清除浏览器存储而丢失。网页不能在后台获取 iOS 屏幕使用时间，也不能保证在页面关闭后推送提醒。每天早晚的 ChatGPT 定时提醒独立运行。
