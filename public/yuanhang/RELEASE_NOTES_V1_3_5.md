# v1.3.5 — 同步可观察性与恢复备份

## 实际改动

- 云同步前的恢复 JSON 同时保留原学习记录与本机问道存档；自定义图片二进制仍须使用原完整导出。
- 同步页分别显示成功读取、成功上传、完整同步的北京时间，以及待同步变更、冲突数量。学习按记录计数，问道按字段组计数。登录不再是判断同步结果的唯一可见信息。
- 上传过程中发生的冲突也保留本地三方快照，成功合并后清零待处理冲突数量。
- 分享用同步诊断移除账号 UUID、完整冲突数据和待核验任务标识，只保留状态、数量与快照是否存在。原私人恢复快照仍留在本机。
- 问道显示版本及静态缓存更新。未改动 DDL 引擎、处罚规则、故事内容或六套立绘。
