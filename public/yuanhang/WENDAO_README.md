## 启动

Node.js22+；Windows双击 `start-windows.cmd`。或进入yuanhang目录执行：

```sh
node wendao/server/launcher.mjs
# 打开 http://127.0.0.1:8765
node --test tests/*.mjs
```

本地入口与原 `https://jasjs96211-alt.github.io/yuanhang/` 数据来源不同。**先在每个有记录的入口导出完整JSON，不要清站点数据、卸载PWA或覆盖唯一存档。** 迁移详见 `MIGRATION_V1_3.md`。

## 可用链路

日历中新建“DDL”，选择重要/关键及可选精确北京时间。没有时间默认截止日23:59:59.999 UTC+8。旧DDL默认重要，category仍为ddl。每次编辑单调增加taskRevision并保留最近100次修订摘要。

系统曾在截止前看到且仍有效的DDL，一旦真实逾期，首次也立刻严重伤病，两个级别都一样。每任务独立账本，无同日合并及72小时阻挡。页面每分钟检查；关闭应用期间不承诺即时执行，恢复后核对离线学习、完成时间与云端状态。缺完成时间、设备时钟倒退或未完成同步先显示待核验。可点击已核验手动结算，必须先补记实际学习与休息。

身体下限35，同日DDL伤害上限30；每项仍生成独立严重伤势及纪事。48小时只结束急性窗口，之后病中持续。一次疗养/求援/补做每天最多一步，至少4步且经过3天才康复；姐姐每天独立行动可推进次日起的疗养。有效学习映射修为和保护能力，不能刷时长瞬间治愈。爱意/羁绊不下降。

“纠正误判”撤销错误数值及伤势，原历史标记已纠正；“补做与协商”只推进真实恢复，绝不伪造按时完成。未来重伤开关不删除既有历史。普通任务仅EV-03提示，清醒120分钟EV-01及合理目标不足EV-02为轻度反馈，不触发严重DDL伤势。睡眠、休息、疾病可豁免；日目标需用户在设置确认，未确认不自动结日债。
