## 使用与数据入口

继续用原入口 https://jasjs96211-alt.github.io/yuanhang/ 。优先留在原本有数据的浏览器；不要先换域名/桌面来源。

1. 点击顶部“问道·找姐姐”或导航“问道”。初次启用会自动备份当前浏览器的学习数据，不删除或替换旧任务、专注、游戏记录。
2. 设置中核对每日目标、固定睡眠起止。严格模式默认开启，初始处于休息/豁免；点击“我已起床”后才计清醒时间。午睡、休息、身体不适可暂停，也可补记实际休息时段并重算。
3. 使用原工作台学习。问道只奖励启用后的新学习证据；启用以前的记录作为基线保留，仍计入聊天的今日学习摘要。相同学习ID不重复奖励。每日时长奖励上限480分钟；复述、默写、七日复习由用户确认，同任务同阶段只奖励一次。删除学习记录后修为重算，已解锁成就作为历史保留。
4. 修炼页可以给已有学习记录补实际起止时间，不增加第二份时长。离线/后台/跨日先核对：补学习、午睡后确认剩余清醒时间。不知道实际时段时可豁免，不把无观测判为偷懒。
5. 姐姐有每日独立行动及最多两条事件留言。专注时她也研习，不弹窗打断；完成学习后可查看留言。留言是程序事件文案，不冒充后台实时AI。聊天不计为学习。
6. 在线聊天按 `wendao/server/README.md` 配置后端模型地址、名称、API密钥、单价和限额。密钥仅在服务器环境变量，前端不保存。设置“检查模型与用量”显示模型、token和估算费用；未配置单价则不宣称免费。手机需要可达且受保护的HTTPS后端，127.0.0.1仅指当前设备。

## 正史及状态规则

已阅读用户两份AU包，按《修仙长篇·设定与进度》的明确最新修订校正冲突。当前固定在第一卷第九章之后的学宫备考准备期；玩家温无缺、姐姐温知遥，无血缘、选择的家人。已发生和后续规划分开；当前AI不会提前揭晓混沌灵根、学籍、离家、同窗、古妖和雷劫。

妹妹当前以练气三层为起点，入学前最高映射到练气七层；更高突破须正史事件。修为门槛为游戏规则，不反向改写小说。姐姐有健康、疲劳、练气层数、研习、自主行动、温家压力及累积劳损。压力上限100、健康下限35，爱意不扣减。

清醒累计120分钟进行一次条件风险判定，初期警告/疲劳，反复可出现责罚、净化及积累病情；重大事件有前置且至少冷却三天。离线单次最多结算两次压力及三个日结，其他汇总豁免。每日目标按首次激活冻结，不追溯重复罚。睡眠和休息排除。

恢复：学习减少压力；合理休息后姐姐自己温养，每日一次恢复；积累90修为可共同整理规约/传召证据，每日一次改善处境，但不虚构温家已放人。详细后续章节第二阶段开发。

## 存档位置、备份及恢复

| 数据 | 保存位置 |
|---|---|
| 原工作台 | localStorage `sisu_2027_study_workbench_v1`，原键保留 |
| 问道（聊天/状态/剧情） | localStorage `yuanhang_wendao_v1` |
| 首次学习快照 | `yuanhang_wendao_v1_study_snapshot` |
| 导入前快照 | `yuanhang_wendao_v1_before_import` 及原学习键加 `_before_import` |
| 冲突快照 | `yuanhang_wendao_v1_conflict_snapshot`，拒绝静默覆盖 |
| 自定义图片 | IndexedDB `yuanhang_wendao_media` / `assets`，版本键保留旧图 |

导出JSON现在包含学习、剧情、状态、对话、选择及自定义图片。导入先预览、再确认合并或替换。旧版JSON不含问道字段时保留本机问道。增量合并保留当前计时和冲突项；完整替换结束计时。问道合并添加纪事、聊天、已读和无冲突选择，数值以本机为准，不能导入刷奖励。

问道设置“恢复导入前问道”恢复可用的学习与问道快照；恢复前的问道另存 `_before_restore`。原数据页仍能导出导入前/合并前备份，再用JSON恢复。原始代码备份在发布包内 `yuanhang-v3.3-before-wendao.tar.gz`，它是代码备份，不是用户学习数据。

浏览器、桌面独立版、不同域名及本地包仍有各自存储。先在有数据入口导出完整JSON，再到目标入口导入。既有可选云同步仅同步原工作台，不包含问道/聊天/图片；本版本不宣称这些会跨设备自动同步。ChatGPT对话不自动同步到程序，可导出剧情摘要或对话。

清理浏览器或更换来源可能删除本地存档，需定期下载JSON。关闭网页后不保证后台即时提醒或主动消息推送。

## 本地Windows运行

安装Node.js22或更新版，解压后双击 `start-windows.cmd`，或运行 `node wendao/server/launcher.mjs`，打开 http://127.0.0.1:8765 。此来源与线上数据分开，需JSON迁移。仅监听本机，不直接开放到公网。手机继续用原线上入口。
