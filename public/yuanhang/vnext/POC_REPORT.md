# 阶段 1 前置技术切片（未完成正式 P0）

本阶段将行为控制器与渲染端隔离。新文件未加载到生产入口，不替换已有 CG/立绘，
不改 UI、业务引擎、计时器、云同步或 AI 后端。

## 真实实现了什么

- `wendao/bedroom-behavior.js`：确定性阶段控制器，统一动作 ID、阶段、clip、道具挂点、文案、只读 AI 上下文。
- 读书→翻页→放书→倚枕→取盏→轻抿→放回→温养→小憩→渐醒→取书的技术时序。
  页码在翻页结束后改变；“已放下”只在放书结束后出现；双手不同时持书和药。
- 资产完整性门控：缺放书/取书不进入持书，缺取/抿/放药任一环节就不播放用药链。
  `placeholder` 资产必须显式允许；生产默认拒绝。缺素材不声称完成动作。
- 权威位置、急性重伤、姐姐睡眠与时钟争议优先；病中外观不覆盖急性重伤事实。
- 进场 30 秒冷却、点击 10 秒冷却、反应节流、持物关键阶段不插入回应；睡眠不被点击或专注事件唤醒。
- 前台丢帧/后台恢复不补播长时间动作；行为快照可序列化并校验恢复，但**尚未接跨设备同步**。
- 计时只读取输入；完成回应必须有原会话 ID 的完成证据，不把重置或倒计时归零当完成。
- `labs/bedroom/`：独立 Canvas 技术骨架，眼部、手臂、书页、药盏随同一快照运动。
  房间与床前沿用调试几何展示透视和遮挡。这些是程序几何占位，**不是正式人物、游戏场景或分层美术**。

## 本地复现

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

在命令显示的本地端口打开 `/yuanhang/labs/bedroom/`。
此页没有 storage/network API，也不加载正式计时器或业务存档。
默认常速运行 5 分钟；检查翻页→放书→取/放盏→温养→小憩，使用侧栏注入重伤/睡眠/离场/缺素材。
侧栏“计时信号”仅为 fixture 输入，无计时结算；不要把它当成实际专注功能。

无浏览器也可复现实际 JS 执行轨迹：

```sh
node public/yuanhang/vnext/demo-trace.mjs
node --test public/yuanhang/tests/vnext-bedroom.mjs
node --test public/yuanhang/tests/*.mjs
npm run build
```

`evidence/behavior-trace.json` 来自实际控制器执行，使用加速的测试时钟模拟 5 分钟。
它证明阶段顺序，不是五分钟真实墙钟观测，更不是画面录屏。

## 计时 / 旧数据证据

测试加载原 `index.html` 的真实 timer 函数与原 `WendaoBridge`，使用隔离 Map 存档：
开始 25 分钟→学习 10 分钟→暂停 1 分钟→离开/返回场景→restoreTimer→继续 15 分钟。
断言仅一条相同 ID 的 25 分钟记录，旧的 60 分钟记录保留。
这验证计时与控制器边界，**不替代 iPhone/PWA 后台和真实账号跨端验收**。
原 #12 CG/来信、伤病和云同步回归保持执行，没有修改它们的业务源码。
