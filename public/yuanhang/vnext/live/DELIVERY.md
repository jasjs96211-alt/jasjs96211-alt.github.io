## 实际可见动作

- 眨眼：眼周绘制层渐变闭合/睁开，间隔 4–9 秒的有种子不规则序列；交替使用较慢眨眼。
- 进场回应：约 1.1 秒抬眼，随后渐入极轻嘴角变化；局部头部形变很小，保持病中虚弱。
- 点击：复用轻看向玩家/浅笑，短句逐次回应；点击冷却 10 秒，进场冷却 30 秒。
- 呼吸/调息：肩胸及附近衣被小范围网格位移，病中最大位移约 1.4 像素（1536 原图尺度），不缩放/平移整图。
- 小憩：逐渐闭眼、闭眼休息、自然慢慢睁眼；睡眠期间进入、点击或专注事件不强制唤醒。
- 重伤：更小呼吸，只作目光回应，不微笑、不坐起。现有 CG 解锁守卫仍生效。
- 专注开始/暂停/恢复/完成：在可回应且冷却允许时柔和回应，无弹窗，不修改计时。

生产动作序列为：**歇息 → 榻边温养 → 静养小憩 → 缓缓醒来 → 歇息**。
书不存在，药盏始终在榻边；没有声称她正在拿书或喝药。
用户否定的“侧卧读书”候选没有接入。以后读书必须先制作健康允许的倚枕坐起、持书与连续翻页资产。
`manifest.status='approved'` 是原控制器的已解码能力标记，**不代表用户已批准画面或允许合并**。

## 六处夜景

问道书房、听竹小庭、百草药庐、回廊、知遥寝居、望星台全部使用独立夜景 WebP。
灯笼、窗户透光、烛火和受光地面按各场景绘制；有水面的场景保留水面反光。
病中寝居另有夜间底图及小范围烛光脉动。夜间移除全屏蓝膜，并隐藏 #17 的临时叠加灯，避免双重光源；黄昏仍沿用已有表现。
原始日景、原人物 CG、立绘均不覆盖。全部 9 个新素材的来源、规格、尺寸与哈希见 [ART_MANIFEST.json](ART_MANIFEST.json)。

## 可复现体验与视频

安装仓库依赖后按原仓库方式运行，访问 `/yuanhang/labs/bedroom-live/`。
试播页与生产共用 `bedroom-behavior.js` / `bedroom-renderer.js`，支持进入/离开、点击、病中/重伤、昼夜、动作开关及六处夜景预览。
试播页不访问学习存档、AI 或云同步；生产页仍从原地图进入寝居，仅在既有 CG 资格允许时显示局部动画。

- [32 秒原画/局部动作对照](evidence/bedroom-live-demo.mp4)：进入、自然眨眼、12 秒点击、16 秒夜景、24 秒专注事件。
- [连续五分钟状态输出](evidence/bedroom-five-minute.mp4)：1× 行为时钟，歇息/温养/小憩/醒来的真实控制器和绘制器输出。
- [短视频动作记录](evidence/demo-trace.json) / [五分钟动作记录](evidence/five-minute-trace.json)。

视频是 **native Canvas2D 执行生产绘制器的实际帧输出，不是浏览器操作录屏**。
右侧放大面部方便核对，左侧为完整场景；没有用后期视频特效替代游戏动画。
长视频以 60 秒批次导出以限制 native Canvas 内存；各批重放相同种子和时间线后输出连续帧范围，拼接时不重置动作、不加速、不补造帧。

复做视频需要 Node、`@napi-rs/canvas` 和 ffmpeg（Canvas 已固定为开发依赖，不增加浏览器运行依赖）：

```sh
# WENDAO_EVIDENCE_FONT 可指向支持中文的本地 OTF/TTF；本次使用 Noto Sans CJK SC。
node --expose-gc public/yuanhang/vnext/live/render-evidence.cjs
node --expose-gc public/yuanhang/vnext/live/render-evidence.cjs public/yuanhang/vnext/live/evidence five-minute
```
