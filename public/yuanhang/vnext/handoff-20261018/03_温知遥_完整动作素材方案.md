# 知遥寝居 · 正式 2.5D 动作素材制作规格 v1
**核心目标：同一温知遥、同一原画风格、有真正的肢体与姿态变化；病中清弱、真实、节制。**

## 1. 现有美术锚（必须先审阅）
- 原寝居 CG：`public/yuanhang/wendao/assets/zhiyao-recovery-cg.webp`，1536×1024、合成静帧；作为一致性视觉锚，不覆盖原资产。
- 夜景：`bedroom-live-night-v1.webp`；睁/闭眼与迎接：`bedroom-live-greet-v1.webp`、`bedroom-live-closed-v1.webp`；代码在 `bedroom-renderer.js`。
- 当前已上线局部 clip：`recline_breathe`、`blink`、`gaze`、`weak_smile`、`rest_pillow`、`recover_breathe`、`nap_enter/loop`、`wake_slow`、`fingers_on_quilt`、`restrained_cough`、`idle_glance`、`severe_rest`。
- **重点缺口**：完整独立手/前臂/衣袖/骨骼、眼嘴独立源层、半坐姿、翻书和药盏手部过渡。原 CG 把手放在被上，药盏在床外右下；不能只“抓住”原手像素平移至嘴边，因为遮住的前臂及袖内侧根本没有画出来。

## 2. 人物设定锁（统一图像生成/修图提示词）
> 温知遥，清瘦温柔的古风女性，病中倚卧于木雕床榻；长黑棕发自然散落于枕上和肩前，青绿色为主、浅金纹绣的宽袖古装；面容与现有原画一致，眼神疲乏清澈、唇色克制，玉色耳坠/颈饰保持正确形态；细腻写意国风、清雅高完成度 CG，光线暖柔、材质真实，场景人物同一透视；动作安静而节制。**不换脸，不变发型衣装，不高亮大笑，不撒娇卖萌，不夸张疼痛，不凭空增加手臂/手指，不修改原有角色年龄气质。**

**正向制作标准**：同一画布位置/视角/头身比例、眼耳位置、衣领纹样和枕头/袖口遮挡。先生成整张关键姿势参考、逐张对照确认；随后用绘画软件补绘隐藏肢体、切分 RGBA 分层并校正遮挡。真正可用的分层素材要有可编辑源工程、锚点与 alpha 边缘检查。

## 3. 动作优先级与连续分镜（严格不能省略中间动作）
### P0-1 真正「抬手掩嘴轻咳」——最高优先级
**与当前 `restrained_cough` 区分，后者只有身体压咳，没有抬手。**
| 阶段 | 建议时长 | 姿态可见事实 | 必要资源 |
|---|---|---|---|
| C00 病中静息 | 持续 | 手轻搭在被上，目光低垂 | 卧姿整装、呼吸/脸层 |
| C01 察觉不适 | 0.4–0.7s | 呼吸轻滞、眉心微蹙、肩稍收 | 眉、眼、肩/衣被小网格 |
| C02 抬臂 | 0.7–1.1s | 手从被上**离开**，前臂从袖中自然露出，缓抬向嘴角 | 上臂、前臂、手、独立前/后袖、被缘遮挡 |
| C03 掩嘴 | 0.2–0.4s | 手背/袖沿到唇前，面容不被整幅遮住 | 手指压弯细节、口部前遮挡、嘴/鼻关系 |
| C04 轻咳 | 0.9–1.6s | 一至两次**很轻**的咳嗽；头肩一缩、胸息收住，再轻吐气；手臂稳定挡在嘴边 | 头/颈、肩胸、口部、袖口、手随动 |
| C05 回气 | 0.6–1.0s | 咳止，眼睫垂下，呼吸重新平稳，稍显疲乏 | 下眼睑、头部回位，气息曲线 |
| C06 放手 | 0.8–1.3s | 前臂缓缓放下，袖沿归位，掌心重落在被面 | 手指-被面接触形变、前后遮挡 |
| C07 静息 | 2–5s 冷却 | 继续倚卧；可能看一眼玩家，但不主动大笑 | 回到 C00，自主微动作重获调度 |

**建议剪辑总长**：约 4–6 秒（具体按实际帧确定，不必硬定）。**触发**：病中且清醒时不规则、低频偶发；可受聊天中“咳”内容和既定健康状态影响但不能由 AI 直接越权请求动作；重伤极虚弱时**不自动完整抬手**，优先保留微喘/闭眼或有专用安全版本。绝不把咳嗽触发本身等同新增扣血。

**资产至少**：`arm_back`, `forearm`, `palm`, `fingers`, `sleeve_back`, `sleeve_front`, `hand_mouth_occlusion`, `quilt_front`, `shoulder`, `head_neck`, `eyes_brows`, `mouth`；所有层维持同画布坐标，关键帧 0/25/50/75/100% 与接触点标注。注意当前原画可见手在画幅 x≈850–1030、嘴在 x≈1124、y≈360（以 1536×1024 当前画幅为初始参考；**精确坐标以切图测量为准，不得盲信这些近似值**）。

### P0-2 更自然的病中呼吸——可立即优化代码，但必须配合画面 QA
- 不用稳定一条 `Math.sin(t)` 循环。设计**短吸、略长呼、零星轻停顿**，间隔与幅度缓慢浮动；不要出现毫无医学/叙事根据的夸张屏息、急促抽搐。
- 建议病中一次周期约 **4–6 秒的缓变范围**：吸气约 35–42%、呼气约 50–58%，末尾轻停约 0–12%，数字仅供动画师调节，不是写死生理参数。
- 同一呼吸 phase 驱动胸肩、衣被、袖口（不同幅度/延迟），下颌只细微跟随；体位固定，背景/枕/床/盏完全稳定。
- 抬手、咳、入睡/醒来、玩家进场时用姿态控制器**柔和混合**，禁止动作叠加使身体畸变。咳嗽时短暂“吸气中断→两次轻促→逐渐回到当前周期”，不从 0 度重启导致跳帧。
- 突发重伤降低动作幅度并优先休息；合理午睡只保留更弱的自主呼吸，不附带笑和自主手势。
- 验收包括手机实际场景全画幅观察（不是只看放大面部）、耳坠/长发是否穿模、床沿是否保持静止。

### P1-1「倚枕半坐／放松卧回」
**前提：规则引擎确认可以半坐，不是剧情文案写“伤好了”。**
1. 卧榻→睁眼、呼气；2. 轻放手扶住身侧/床沿；3. 肩/胯轻移、上身撑起；4. 拉整靠枕/被角；5. 倚枕半坐后稳住气息；6. 可以继续读书/饮药；7. 返程必须有单独过渡链，不能直接硬切回卧姿。
需要：卧姿/侧卧/半坐核心姿势、两臂、肩胸后发、袖口、枕/被变形与 z-order，**不得让腿或手在被褥下凭空出现**。建议过渡 5–10 秒，并允许中断时安全落回现有动作位；重伤禁止。

### P1-2「取书→持书→翻页→放书」
1. 手从被面抬起与医札接触；2. 双手/单手稳定持书并有正确厚度；3. 目光转向书、时长自然随机；4. 指尖捻住一页；5. **活动页真正掀起、翻过、落定**；6. 页码 `page_settled` 后才能 +1；7. 合起书册；8. 放回床边明确挂点 `book_released`；9. 空手恢复调息。
**前提**是已经进入健康允许的半坐姿；用户此前拒绝“病中侧卧直接翻书”的假动作。必须有至少书封/页块/活动页/手/前后袖独立层。

### P1-3「取药盏→抿药→放回」
1. 手从空闲位伸向床侧药盏；2. 指根与盏/碗真实接触、握牢后才移动道具；3. 前臂/袖沿和杯盏同步抬升，碗液保持重力一致；4. 倾盏到唇前**浅抿一次**（非一口豪饮）；5. 降低盏；6. 重新落回原位后松指离手；7. 恢复半坐/卧姿。
核心事件帧 `bowl_gripped / sip_finished / bowl_released` 要驱动动画事实、纪事与 AI 的只读上下文。持书和持盏互斥；重伤/昏睡不能自动执行。

### P1-4「浅眠/缓醒、取暖、照护」
缓合眼→呼吸更弱→自然转稳→一段时间后缓缓睁眼，非玩家轻触强制唤醒；病中略带倦意，醒来要有眼神/呼吸慢慢过渡，不需甜蜜夸张微笑。若玩家递暖符/安抚，可在既有事件得到规则允许的前提下出现“衣被轻拢/掌指略蜷”的回应，不可让新动作擅自发放疗伤数值。

## 4. 分层清单（源文件+导出）
要求**至少这些可编辑层**；根据真实绘图可以扩展，但不能缺实际参与动作的部位。
| 层组 | 建议文件/动作需要 | 关键检查 |
|---|---|---|
| BACKGROUND | `bed_bg`, `window`, `curtain`, `pillow_back`, `bed_rail_back` | 不随人物呼吸抖动，昼夜分光 |
| HAIR | `hair_back`, `hair_side`, `bangs_front`, `loose_strands` | 头动时耳坠/发丝柔和滞后，无遮挡穿透 |
| FACE | `head_neck`, `eyes_open`, `eyelid_closed`, `gaze_down/player`, `brow`, `mouth_rest/cough/smile` | 五官不变，病中笑幅低，夜间肤色匹配 |
| BODY | `torso`, `shoulder_left/right`, `upperarm`, `forearm`, `hand_palm`, `fingers` | 掩嘴必须真手臂，关节/手指数正确 |
| CLOTH | `collar`, `robe_back/front`, `sleeve_back/front`, `quilt`, `quilt_front`, `pillow_front` | 青绿金纹理连续，袖口从前后遮挡过渡正确 |
| PROPS | `book_cover`, `book_block`, `book_page_active`, `bowl`, `medicine_surface`, `bedside_rest` | 抓握/归位锚点统一，物品不漂浮 |
| FOREGROUND | `bed_rail_front`, `curtain_front`, `hand_mouth_occlusion` | 手在嘴前/袖在脸前时遮挡可信 |
| LIGHT | `night_warm_light`, `day_soft_light`, `local_candle_glow` | 不叠加第二层蓝膜/假灯 |

**源文件**：PSD / Krita / 分层 OpenRaster / 可编辑 rig 工程至少一种 + 透明 PNG/WebP 导出（源图层不可只是一张合成图），原件的许可和生成记录与 prompt 随包提交。每个导出提供逻辑原点/画布尺寸、pivot、z、接触点、背景/遮罩、clip/帧长度、`sha256`、日夜调色方式。静态 sprite 不要自动裁切后无锚点。

## 6. 每批正确流程
1. 从生产原画和人设核对五官/服饰；固定摄影机和 1536×1024 原始构图。
2. **先做关键姿势概念图**：静息、手抬起、掩嘴、咳嗽回气、放回被面；确认是同一个人，才制作中间过渡。
3. 补绘原图不可见部位，制作真实透明前后层、手/袖/被遮挡，做骨架/变形 rig 和道具锚点。
4. 用开发独立试播页 1× 实时展示 30–60 秒：至少 3 轮无缝动作；可控病中/重伤/睡眠/白天/夜景/低性能场景。
5. 验证帧间没有闪/漂浮/断肢/关节异形/图案跳纹；在 iPhone Safari/PWA 观察人物大小是否有实际可感的自然动作。
6. **只有素材已解码、视觉验收通过的 clip 才解锁生产**；其余仍保留当前已批准动作，避免造假。

## 7. 可直接用于制作首批参考图的提示结构
**输入必须提供原正式寝居 CG 作为参考锚；**不同动作沿用同一参考，不靠纯文字反复抽卡。

- **基础风格约束**：保持温知遥现有五官/发丝/饰物/青绿浅金衣纹/寝居床榻构图、国风写意 CG 原画风格，不要更改镜头朝向；病中气弱、倦怠、安静善意、笑意极轻。
- **掩嘴关键帧**：同一人物保持卧榻姿势，手从被上慢慢抬起，宽袖衣摆随真实重力下垂，指背/袖沿轻掩在唇前，略蹙眉轻咳，眼神疲惫；头颈和靠枕接触自然；不是突然坐起，不夸张咳血，不新增另一只手。
- **半坐关键帧**：身体仅在伤势允许时缓缓侧撑倚上枕，轻扶被面，衣领/袖口随姿态回落，原窗竹/床栏机位不动、脸部识别不变。
- **持书关键帧**：在已经半坐的姿势用手持医札，真实纸页厚度和柔软翻页，手指与书页接触，不画成侧卧手里凭空出现书。
- **端药关键帧**：在半坐/可扶起状态下真实伸臂握持药盏，杯盏位置与原木桌对应，袖口贴合腕部；只浅抿、不夸张饮尽，放回完全对准原挂点。
- **反向约束（每张都带）**：no different character, no altered facial features, no changed outfit or jewelry, no extra limbs/fingers, no doll-like 3D, no flat chibi, no giant smile, no exaggerated motion, no random cup/book teleportation, no changed camera/perspective, no floating whole scene, no blue-filter-only night.

**画面参考不等于可用资产**：若生成的是整张“她在掩嘴”的好看图，仍需要美术端切出确实可操控的手、袖、头、前景遮挡，做连贯接触点才能交给 Codex。
