# 验收标准、回归范围与下次交接回执模板

## 1. P0 自动检查
- 角色动作与世界授权：健康许可才半坐、读书、抿药；重伤/睡眠禁起身、禁掩嘴大幅动作；对话/进场只产生可允许的眼神/微笑。
- 行为一致性：`title/text/actionId/clip/props/forAI()` 同源；任何 clip 解码失败时文案降级，不写“她端药了”却没有端。
- 呼吸/咳嗽曲线：无需匀速正弦，无跳变，无 0→瞬间满幅；切入咳嗽/切回呼吸连续；身体局部像素改变而背景和药盏位置不动。
- 手/袖/掩嘴：腕/肘连续轨迹、指头数和口部遮挡正确；咳嗽完成后手回到被面，不能永久僵在脸前或出现断手。
- 书与药互斥、动作阶段占位有效，书页只有真实完成翻页才算更新；药盏真实 grasp/release 之后才更改位置。
- Canvas/静态缓存：图层热加载、资源失败回退、旧 CG 解锁守卫、减少动画、离屏暂停与返回、iOS PWA SW 版本、弱网/省流兼容。
- 夜间纪事：时区 Asia/Shanghai、跨日、排序、空事件、重复 ID、旧版本 recap 回放、离线补算限制、跨端合并、剧情门控、不生成未经许可主线、不因描写改变任何数值。
- 老数据：既有学习计时 25 分钟暂停再恢复只结算一次；60 分钟旧记录仍在；DDL 首次逾期仍急性伤病，48h 后持续影响仍保留；消息来源与世界地点不矛盾。

## 2. 必须做真实视听 QA，而非仅仅测试通过
**共同镜头**：与现有 `zhiyao-recovery-cg.webp` 同角度，昼夜分别连续录制 30–60s 常速；包括「进场/闲置/呼吸/咳嗽/浅眠/醒来」，需要素材的动作单独录完整 1× 流程。展示全场景与人物脸手局部放大；**明确每段是桌面浏览器、原生 Canvas 导出还是 iPhone Safari/PWA 屏录**。

### 手机人工验收观察表
| 场景/操作 | 必须看见 | 失败特征 |
|---|---|---|
| 待机 30s | 呼吸轻重不完全重复、眼神细变化 | 整张画上下晃、像呼吸机般机械 |
| 病中掩嘴轻咳 | 手离被→挡口→轻咳→放回，宽袖和手同步 | 手凭空飞起、袖子和手断开、只肩膀颤就报“掩嘴” |
| 夜间寝居 | 烛火局部暖光、五官/手不换脸、不突兀蓝染 | 整图加蓝膜、灯具不照场景 |
| 受伤/睡眠 | 不起坐、不端盏、不被点击强制唤醒 | 一点击就站起来/剧烈变化 |
| 放书/取药 | 物件挂点正确、物理接触可信 | 道具瞬移、透过手掌/前景 |
| 关闭再进 | 无补播 10 分钟动效、旧数据还在 | 连环动作追帧、学习重复计入 |
| 夜间纪事 | 00:00等确有时刻排列，多晚不机械雷同 | 只有一大段报告、无源假事件、时间错位 |
| 地图/书房 | 独立地图、六处夜景、照旧可专注 | 地图被收进陪伴、HUD 挡角色、夜景变蓝膜 |

## 3. 必要工程证据
- 新资源 manifest 包括 path、源文件、大小、宽高、alpha、有无遮挡层、sha256、映射的 clip ID、首尾姿势、关键帧、pivot、QA 审查人/结论。
- `node --test public/yuanhang/tests/*.mjs` 全通过，`npm run build` 通过；若项目有其他 CI，保留历史测试全部通过的记录。
- 新增真实 Canvas 像素回归（在几何/实际绘制层证明局部像素改变且环境不动）；说明性能测量环境/持续时间，不拿 native 模拟假称手机 30fps。
- 按北京时间和至少另一时区跑 chronicle/DDL/离线测试；携带旧 snapshot 模拟版本迁移；跨设备同 ID 冲突合并无重复。
- 真实 Safari/PWA QA 不可用则写“未完成实机验收”，不得写成“全部验收通过”。
- 展示备份点、PR 链接、主分支 SHA、发布结果，代码证据能验证。

## 6. 新增需求纳入机制（用户明确要求的长效纪律）
用户之后每次说“可以、好、就这样”同意某个视觉/剧情/游戏化点，交接维护者必须在下一包中：①写进本总账新 ID；②写进具体素材或开发规范；③写进可复制指令；④写进验收条件；⑤对已发布/待做状态给证据。**绝不只把上次聊过的十条合并成一句“优化自然度”。**
