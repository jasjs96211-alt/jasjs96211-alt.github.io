# 2.5D 方针——决定视觉效果的底层路线（硬性约束）

## 目标气质：方案 C
**写意国风场景 + 精致 RPG 质感 + 橙光/易次元剧情层次 + 《恋与深空》式陪伴沉浸感。** 氛围可参考早期《金庸群侠传 OL》里“人物确实住在地图里”的感受；参考的是体验原则，绝不复制角色、UI、图像或技术形态。

**不是**俯视像素沙盘、斜45°无脑等角地图，不是强行 3D 化，也不是几张 2D 背景上放张会漂浮的立绘。主要镜头为平视/微俯/微仰、人物靠近的叙事摄影机，在六个有联系的生活场景中形成有空间深度的视觉小说/RPG 混合体验。

## 2.5D 分层结构（先寝居，再推广）
- **L0 远景**：窗外竹影、天空、月光层；仅极缓的真实材质/光线变化。
- **L1 建筑内景**：窗、屏风、墙、柜、桌、床后沿；固定的透视基准。
- **L2 中景人物后层**：后发/脑后鬓发、靠枕后缘、衣物后片、坐卧后臂。
- **L3 角色骨架/形变层**：头颈、胸肩、前臂/手、袖口、衣裳、被褥与饰品各自转轴和拉伸/变形约束。
- **L4 可交互道具**：医札、翻页、药盏、杯中药、书台，使用**同一世界坐标锚点**。
- **L5 前景遮挡**：帷幔、床前雕栏、前沿被褥、头发叠层，正确遮住手臂和道具。
- **L6 暖光与环境反馈**：日/暮/夜独立背景配色，烛光微动、灯笼和窗光在地/水有反射；不能蓝膜覆盖代替。
- **L7 最少 UI**：简化属性 HUD、对话、独立地图与陪伴入口，避免覆盖人物脸和双手。

这里的“层”是职责而非必须只有 8 张图：真正在动画系统中可切成更多分层（髮、手臂、衣袖、手指、衣被、窗光等），并用脚本描绘遮挡关系。

## 镜头与移动
1. **寝居 P0 固定叙事机位**。现 CG 1536×1024 是构图锚：眼、下巴、手、药盏的相对透视保留；前景被褥/床栏应提供遮挡。动画不能把整体 CG 当作人物 rig。
2. 人物进出场采用锚点/路径/缓入缓出，视觉上“走过去并被建筑/屏风遮挡”，而不是快闪或线性平移静态图。
3. 独立地图显示六个地点连接；与主界面「陪伴修炼」分开使用，不能强迫先专注。有限前后左右连通已经存在，后续可加路径演出，但**当前不宣称开放 3D 自由行走**。
4. 主角同行必须遵守世界状态：伤病、精力低、温家事务、夜间休息时不能强行跟随；姐姐不在当前地点则不应在画面里突然出现。
5. 机位切换、景别与视差遵守“写意的真实感”：2.5D 空间里有光、风、遮挡、远近层差，但不把人物变成违和的伪 3D 玩偶。

## 场景优先级
| 场景 | 当前基础 | 下一阶段 |
|---|---|---|
| **知遥寝居（P0）** | 病中 CG、脸部/呼吸/手指/压咳、夜景已入生产 | **掩嘴咳、可见倚枕、取书、翻书、放书、取盏/抿药/放盏、入睡醒来连续体位过渡** |
| 书房（P1） | 既有翻书/阅读 4 帧动作；昼夜背景 | 真正拿书、翻页、疲倦伏案、目光看向玩家、案上烛火与手部互动 |
| 药庐（P1） | 分拣药草动作与夜景 | 捏/拿/放药草，手与药架空间一致 |
| 听竹小庭（P2） | 空间和灯光基础 | 低速行走、驻足、竹影风动；情绪低时独坐 |
| 回廊（P2） | 左右行走与灯光基础 | 分层远近遮挡、行走进出、书信拿放 |
| 望星台（P2） | 远景、夜色和灯光基础 | 远眺、轻缓倚栏、云/月/水面反光（若场景画面有水） |

## 技术路线与端侧预算
- **首选渐进增强**：沿用仓库现有 JS/DOM、`WendaoBedroom` 行为控制器与 Canvas2D 正式绘制器；可加 sprite atlas、离屏缓存和最小骨架层，但不为追求引擎名号直接全量迁移 Pixi/Phaser。
- 如要用 Live2D/Spine，需要交付可运行的资源格式、可编辑源文件、运行时许可及手机性能验证。仅有 GIF/合成图不是分层资产。
- 优先 `requestAnimationFrame`，屏幕 30fps 目标；后台暂停视觉推进，页面重新可见后继续，不补播离线时数。电量节省、减少动画设置及加载失败必须降级原画，不强行做慢动作。
- iPhone Safari/PWA + 桌面浏览器做真实视觉测试；不得把 Node Canvas 的视频当作 Safari 屏幕实录。
- 人物行动、聊天文案、纪事、家族压力、健康、时间统一共享来自规则引擎的只读状态；人物动画的中间阶段绝不能单独结算学习/伤病/物资。

## 不在本批优先实现但不能丢失的策略
场景转场流畅度、六场景的完整 2.5D 远近遮挡及自主行走、主动来信与地点一致性、BGM 和未来可调提示词/参数仍写入 backlog，优先级在**人物完整动作+夜间纪事**之后；已做的昼夜夜景、主界面地图不可回退。
