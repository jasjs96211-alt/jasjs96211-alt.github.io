# 知遥寝居：正式动画资产交付规格

状态：**缺素材，未达到正式 P0**。现有 CG 仅作为角色脸型、长发、玉饰、青白金绣衣着参考。
不得用整幅 CG 浮动替代以下部件，不从合成大图臆造被遮挡的手臂。

## 文件和坐标

逻辑画布建议 1600×1000（非鸟瞰，平视略俯）；RGBA PNG/WebP 层或可控帧序列。
每层导出保持同一画布原点，注明 pivot/anchor 与 z；不得自动紧裁导致帧间跳位。
手机镜头需保留面部、持物双手、药盏与书在中央可视区，横屏保留床榻空间。
优先交付 PSD/可编辑分层源文件 + 导出层；若用 Spine/Live2D 需交付对应 runtime/许可信息。

| 文件组 | 必须包含 | 支持的动作 |
| --- | --- | --- |
| bedroom-scene | 后景墙窗、床后架、床褥、近景帘、床前沿/被褥遮挡、空书/药盏台面 | 纵深与前后遮挡，固定 bed/book/bowl 锚点 |
| recline-body | 后发、头颈、躯干/肩/衣袖、被褥（真实可形变）、前发、左右臂手 | 卧姿/倚枕呼吸，不整体漂浮 |
| face | 左右眼白/瞳孔/眼睑开合、眉、闭嘴与浅笑、病中与重伤表情 | 眨眼、看书→看玩家、有限微笑 |
| read | 持书双手、独立封面/页块/活动页、翻页手袖、放书连续帧 | 读书、手指掀页、完整放到侧边 |
| medicine | 空闲手→握盏→抬盏→抿药→放回的手袖与盏；接触点一致 | 真正端药，不与持书同时发生 |
| rest/nap | 卧/倚枕/半坐姿势、连续过渡；闭眼浅眠与手部静放 | 收书→休息→温养→小憩；重伤不坐起 |

## Clip 契约（不能只提供名称）

每个 clip 包含 id、姿势、frame/骨骼数据、真实时长、loop、可中断点、所需层/道具、
事件帧、source hash、`status: draft|approved`。素材未解码成功不算 ready。

| clip id | 可见事实 | 事件/后置条件 |
| --- | --- | --- |
| recline_breathe | 胸肩/被褥局部呼吸，面部原地 | 不改变任何长期健康字段 |
| blink / gaze / weak_smile | 真实眼睑闭合、瞳孔移动、嘴部弱笑 | 睡眠不响应；重伤不强制笑 |
| read_hold / page_turn | 手持书，真实页运动，视线在书 | `page_settled` 后页码才改变 |
| book_put_down | 双手将书从阅读挂点放至床侧 | `book_released` 前文案仍是“正在放下” |
| rest_pillow | 无书在手，头肩倚枕 | 不能声称已服药 |
| bowl_take / bowl_sip / bowl_return | 手与盏接触、一起运动、再落桌 | `bowl_gripped / sip_finished / bowl_released` |
| recover_breathe | 盏已放回、倚枕缓息 | 不解除伤势、不颁发学习奖励 |
| nap_enter / nap_loop / wake_slow | 合眼并保持卧姿；醒来有过渡 | 没有权威清醒事件则不能被点击叫醒 |
| severe_rest | 平卧微弱呼吸/缓睁眼 | 禁止读书、坐起、行走和热情迎接 |

## 验收源文件

提供至少一段未剪切 30–60 秒演示，能看到：读书/翻页→放书→倚枕→取盏/抿药/放回→调息。
眼睛与手不可被 UI 遮挡；源图和截图并排检查同一人物识别度。
做不到的 clip 标为 missing；缺药盏动作时只显示“歇息”，禁止声称“用药”。

第一批优先：卧姿分层 + 面部 + 翻页/放书；第二批：盏/手与倚姿过渡。
在这些资产通过 QA 前，代码技术排演只能标 `placeholder`，不得升级为 approved。
