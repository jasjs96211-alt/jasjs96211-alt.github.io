# v1.6 演出资源来源与制作规格

所有新角色图使用内置 `image_gen` 生成；没有使用新的API Key或修改游戏的AI服务。人物参考为现有 `sister-calm.webp` / `sister-ill.webp`，白日书房参考原 `study-room.webp`。原六套人物、原书房和原CG文件保持原字节。

## 最终生成提示词/规格

通用人物约束：同一位温知遥，温柔年轻的面容、深棕长发、玉饰、浅青与象牙白金绣衣裙、深青腰封；保持参考的2D绘制风格。非性化、衣着完整，无字、无水印。动作图请求真实透明背景；精确2×2等分四帧，同一比例、基线和安全边距，不能用重复站姿代替动作。

- **行走**：面向右侧的四个连续步态，左脚迈出、经过姿态、右脚迈出、反向经过；袖摆与手臂自然摆动，裙下可见交替脚步。完整人物均留在各格内。
- **读书**：真实坐在矮凳上，手持摊开的医书；四帧依次低头阅读、抬起书页、翻页并眨眼、手落回新页。头部、凳子、书本位置基本一致，手/书页/眼睛确有变化。
- **药草**：同一人物立在小木制药草工作台前；依次伸手取草、抬起一枝辨认、移向另一堆、放回并松手。各帧保持人、案、衣着一致。
- **调息**：实际盘膝坐于编织蒲团；睁眼放松、合眼结小印、吸气时肩手轻抬、呼气时双手舒展与半睁眼。不得使用站姿或用特效遮挡姿态。
- **卧床CG**：以病中原立绘为人物参考，独立横幅完整场景。温知遥真实侧卧于中式木榻，头靠象牙白枕，长发放散，无高发饰，完整青白衣裙与被褥遮盖身体，手搭被面；疲倦苍白、半合眼、无笑、无血腥。竹窗、药盏与柔和灯光；脸在中右侧，适合手机裁切。不是站姿贴在床前。
- **六处背景**：学宫书房、青溪药庐、听竹小庭、学宫回廊、知遥寝居、望星台。精致中式2D场景，浅青、象牙白、木色，明亮自然日光，主要环境线索集中于中部60%；无人、无动物、无文字、水印或界面。药庐含药柜/药草工作台；竹庭含竹、石径和池塘；回廊含木柱与庭院；寝居为空榻、青色帐与药盏；望星台含石栏和远山。白日书房只将原房间夜色改为09:00自然日光，保留家具与构图，原夜图另存并继续用于夜间。

## 实际交付格式

角色图实际返回1254×1254透明图集，等分为627×627的四帧并导出动画WebP及首帧静图。裁切/编码仅用于部署，未通过程序生成或重画人物内容。确切帧时长、文件大小与哈希见 `MOTION_V1_6.json`。

| 动作 | 动画文件 | 静图降级 | 四帧时长（毫秒） |
|---|---|---|---|
| 行走 | zhiyao-walk-cycle.webp | zhiyao-walk-still.webp | 240 / 240 / 240 / 240 |
| 翻书 | zhiyao-read-cycle.webp | zhiyao-read-still.webp | 4200 / 650 / 700 / 2450 |
| 分药 | zhiyao-herbs-cycle.webp | zhiyao-herbs-still.webp | 1500 / 1200 / 700 / 2100 |
| 调息 | zhiyao-meditate-cycle.webp | zhiyao-meditate-still.webp | 1600 / 1900 / 1600 / 1900 |

卧床CG：`zhiyao-recovery-cg.webp`。六背景：`world-study.webp`、`world-herbs.webp`、`world-garden.webp`、`world-corridor.webp`、`world-bedroom.webp`、`world-terrace.webp`。

这是四张关键姿态循环的2D动画，不是Live2D/Spine骨骼动画或高帧率视频。卧床资源为独立静态CG。立绘与环境的脸型/风格一致性、步态连贯性、手机裁切和坐卧姿态仍需用户美术/真机验收。既有伤势决定可用动作，演出本身不扣血、不加修为、不生成学习。
