## 可审阅内容

- 独立页：`/yuanhang/labs/bedroom-space/`，从原工程的静态服务访问。
- 单文件：同目录 `bedroom-space-r1.html`，已内联运行时代码、样式及原 CG 降级画面，可下载后打开，无 CDN 请求。部分文件预览器可能禁用 WebGL；应在支持 WebGL2 的浏览器中运行。
- 真实几何：9 × 6.9 m 寝居；床、床柱、枕被、屏风、门、窗格、床侧桌、书、盏、两个纸灯及窗外竹竿。前/右墙为明确的剖面开口。

- 进场沿门口、屏风后、绕屏风通道抵达床侧，采用真实深度检测；路径以 0.32 m 身体半径检查碰撞。

- 45 秒巡览以可见页面时间推进。后台不补播；暂停、减少动态及环境微动开关可用。

## 技术选择与边界

选用固定 `three@0.180.0` 的 `three.module.min.js` 和 `three.core.min.js`，MIT 许可随包保留。依赖仅由隔离试验页按需加载，原主页面、PWA 缓存、根 package/lock 不变。将本地 ES module 当普通静态资源发布，避免 import map、远端 CDN 与构建插件耦合。Three 该版本要求 WebGL2，失败或上下文丢失时显示原 CG 并明确标注“静态降级”，不冒充成功启动。

`contract.js` 只读接收 world/state/睡眠与显式姿态许可；不导入 engine、transport 或存档代码。地点不在寝居则人物隐藏；重伤、病中、睡眠、时间争议阻止行走，重伤/睡眠禁止半坐。当前页面全部是手动模拟事实，**尚未接入正式游戏快照**。

本轮不使用单张人物 billboard。没有新增正式角色原画，也没有尝试将无分层 CG 切成平面身体；代理是显式的无脸体积测试件。正式角色路线仍待比较：

| 路线 | 后续要解决的问题 |
|---|---|
| 高质量 2D 骨骼 + 3D 房间 | 正面/侧面姿态原画、分层源文件、受光和接触阴影、机位受限时的纸片感 |
| 风格化 3D 角色 + 3D 房间 | 面部与衣饰一致性、角色建模/拓扑/绑定、柔软被褥、自然持物和病中动作 |

当前灰盒不能证明其中任一路线已达到目标美术质感。
