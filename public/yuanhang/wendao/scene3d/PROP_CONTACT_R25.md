# 寝居 R2.5：占位道具接触与安全收尾

日期：2026-10-26。延续 R2.4 光照、只读生活接线和不透明屏风。人物仍为无面容几何代理，用户正式人物资产不改。

## 本轮行为

- 书案书册和药柜药碗是独立世界节点，每件仅一个实例；伸手阶段留在承托面，接触后连续搬运，放稳后松手。床边原有书碗属于另一处陈设。
- 占位上臂/前臂各 0.32 米，双手通过两段解析约束跟随握点。书册握点为局部 X ±0.145 米；药碗为 X ±0.085、Y 0.045 米。没有修改或生成温知遥脸、衣服或正式骨骼。
- 阅读结束保留持书；选择下一行动先放书，取消按钮此时仍可用。药碗从柜前托板取回并归还。服药仅视觉演示，不代表真实用药与结算。
- 取消伸手、搬运、抿药和回放时，完成当前转移再归还；反复取消不重启动作。坐卧转移继续先到达支撑面。取消放书后重新行动使用实际书案接近点，不使用尚未到达的药柜坐标。
- 权威健康/睡眠/在场许可变化仍立即重置并归位，不为“自然收尾”延长已禁止的动作，也不在恢复后补播。

## 坐标与生命周期

| 道具 | 静置中心/底面坐标（米） | 支撑 |
| --- | --- | --- |
| 书册 | (-3.22, 0.8875, 1.85)，中心 | 书案面 Y=0.87；书厚 0.035 |
| 药碗 | (1.55, 1.145, -2.62)，底面 | 新增柜前托板顶面 Y=1.145 |

`character-adapter.js` 导出 `PROP_HOMES`。`createProxy().propsRoot` 必须与人物 root 同级放入世界场景，不能挂在人身上；人物暂离时陈设保留。`setPose` 用于权威重置，会让道具归位；常规流程必须用 `transitionTo`。`propContacts` 仅供诊断/测试，返回拷贝，不驱动业务。

`action-flow.js` 复用原队列，增加 `return-book` / `return-bowl` 和 `status.canCancel`。读取完成的持书状态允许取消；新任务会先释放当前持物。场景替换为正式 GLB 时移除占位道具根并纳入销毁，正式模型不自动套用代理 IK。现有 GLB 片段与握点校验保留；正式拿放仍待适配，不能将本轮代理测试视为 GLB 动画验收。

## 验证与边界

- Node 全量回归 405/405，通过；新增 6 项测试覆盖 30/60/120 Hz 取放连续性、握点误差、单一道具实例、伸手不提前搬物、8 个阶段取消、阅读后取消、放书取消后的接近点、权威归位和外部状态不变。
- 这些是几何/时间逻辑自动测试，不是渲染性能测试，不能推出实际设备 30/60/120 FPS。
- 尚缺正式手指、袖口、翻页、脚底支撑与衣摆碰撞。书册没有真实翻页动画；不可把“展开书册”阶段标签当成该细节已完成。
- 浏览器 GPU 画面、手机 Safari/PWA 和动画录屏仍须实机验收；最新浏览器结果见 `../HANDOFF_CURRENT.md`。
