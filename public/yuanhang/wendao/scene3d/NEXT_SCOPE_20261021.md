# 《远航·问道》下一阶段范围（2026-10-21 生效）

本文件覆盖旧交接稿中 AI 人物建模、转面生成和以人物完成为前置的安排。历史记录与收藏资产保留。

## 已确认分工

温知遥的面容、身体、服装、最终模型由用户制作。AI 停止人物生成、重塑和美术试错，不调用人物生成服务、不消耗此类额度、不覆盖或删除收藏。占位体积代理仅用于功能验证，不能当成人物成品。

AI 持续负责真实 3D 寝居、环境陈设、灯光、固定 2.5D 正面微俯镜头、导航、交互锚点、动作调度、模型接入与性能。开发不等待正式人物。

## 当前代码样板

入口 `/yuanhang/labs/bedroom-space/`。在既有 R1 上增加书案、凳子、药柜和碰撞边界；六种行动入口为行走、坐下、看书、服药、卧床、休息。有限网格路径绕开实体家具，身体半径 0.32 m，速度上限 0.65 m/s。到点后切换占位体位和书/碗道具，尚非自然坐卧、拿取或吞咽动画。

晨昼暮夜和灯火开关保留：窗外方向光、室内暖色点光、接触阴影；下一轮需实际 GPU 画面后调整参数，不以参数存在宣称夜景质量通过。移动端默认低性能档，像素比 1、方向阴影 512，关闭点光阴影；普通档像素比最高 1.5、方向阴影 1024。保留 44px 手机点击区、后台暂停、减少动态和 WebGL 错误降级。

## 业务保护与后续接线

现阶段样板使用合成快照，没有接入生产存档，不改主线、计时、DDL、健康、昼夜、自主生活或离线纪事。原系统保持原样。

正式接线顺序：原业务系统产生只读快照和许可 → `setSnapshot` → 原自主生活调度器调用 `requestActivity` → 场景演出。场景不得自行扣血、恢复、消费药品或结算学习；演出成功也不代表业务服药成功。正式接线尚待开发和回归，不能称作自主生活系统已经接入。

重伤、病中、睡眠、离场、时间争议限制主动行动。健康变化立即取消路线。离线时由原业务系统生成纪事，场景不补跑整夜动画、不惩罚睡眠、不用随机事件破坏主线。

## 标准 GLB 接口 v1

| 项目 | 契约 |
|---|---|
| 格式 | glTF 2.0 二进制 GLB；由固定版 GLTFLoader 解码后传入 `scene.attachGLB(gltf)`；该函数不联网、不覆盖源文件 |
| 单位与朝向 | 1 单位 = 1 米，+Y 向上，人物面向 +Z；地面 Y=0；默认身高约 1.65–1.75 m，可按用户最终模型校准场景，禁止擅自改人物比例 |
| 根节点 | 独立运行时实例，缩放 1，无负缩放；站姿根节点在双脚接地中点；位置和朝向由场景控制 |
| 骨骼 | 单一 humanoid 骨架，骨盆/脊柱/胸/颈/头、左右臂手、腿脚；允许 Mixamo 命名；动画与模型使用同一骨架，跨骨架动画必须先明确重定向映射 |
| 动画片段 | 精确映射 idle、walk、sit、lie、read、medicine、rest；原地动画，不在 XZ 方向做根位移，避免导航与动画重复移动 |
| 接触约定 | sit/read 片段原点为坐骨接触面；lie/rest 原点为床面躯干支撑点；片段内部处理脚、躯干相对根节点位移，不能把模型原点永久移动到骨盆 |
| 模型锚点 | grip_left、grip_right、head_anchor 三个命名节点；手持物挂接，不写入模型文件；正式坐卧另校准 pelvis/feet 的接触偏移 |
| 场景锚点 | `contract.js` 与 `interactions.js` 为运行时权威；书案接近点 (-2.1,0,1.8)、座位 (-2.75,.52,1.85)、药柜接近点 (1.55,0,-2.1)、床侧 (.52,0,-.65)，均为米 |
| 预算目标 | 手机角色建议 ≤40k 三角形、1–2 套 2K 贴图、≤80 骨骼、≤6 材质；目标为初始建议，按实际手机测试调整 |
| 失败处理 | 缺片段/锚点时拒绝替换，保留现有代理；不修改用户模型来自动补齐 |

已预留 `createGLBCharacter`/`attachGLB`；未使用用户正式 GLB 验证，不声称正式人物接入已完成。实际到货后验证比例、骨骼、片段、握持、脚底、坐骨、床面和衣摆穿插。

## 验收与推广门槛

1. 六行动可连续切换，所有接近点互通，无穿屏风/床/柜，状态变化中止动作。
2. 桌面与手机横竖屏实机检查空间纵深、正面微俯、遮挡和操作。
3. 夜景开关灯可见暖光落在邻近表面；月光有方向，不靠整图染蓝；检查阴影伪影。
4. 记录设备和真实 FPS/加载耗时；手机目标稳定 30 FPS，桌面目标 60 FPS，未实测前不承诺。
5. 接入原自主生活前验证存档无迁移/重置，主线、离线纪事、睡眠保护和健康规则一致。
6. 寝居实际通过后再推广学宫等区域。
