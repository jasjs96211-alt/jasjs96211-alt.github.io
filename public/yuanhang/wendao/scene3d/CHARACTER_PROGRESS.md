## 已接好的工程接口

`adaptCharacterVisualState()` 从外部只读事实生成冻结对象：identity、location、worldPosition、posePermissions、pose、health、emotion、phase、action、facing、hair、props。

`withPresentationPose()` 只改变许可范围内的显示位置和姿态；不能改变健康、睡眠、地点或增加动作许可。三维代理和 `selectNarrativeArt()` 读取同一对象；严重伤势优先于心情，人物不在场时两种显示一同隐藏。只有现有画面可用时才显示原 CG；原立绘的站姿与代理坐卧不一致会明确标注。

晨暮切换保留许可内的当前姿态/位置；关闭微动在当前位置停下。该模块不导入业务引擎、不读写存档、不自行补算伤势或时间。

## 当前资源阻塞与可执行制作单

目前可调用的图片工具只能交付绘制图像，现有仓库没有符合温知遥原画的可编辑三维角色、蒙皮、骨骼和面部形变。无法把一张新转面图直接报告成可用的角色 GLB。

| 工单 | 输入 → 输出 | 完成条件 |
|---|---|---|
| ART-01 轮廓锁定 | 原立绘、卧床 CG、本次候选 → 严格正面/90°侧面/背面及微俯面部对照 | 统一脸宽、眼鼻口比例、发饰与衣装结构，修正当前 PROFILE 偏转 |
| MODEL-01 角色建模 | 锁定设定 → 可编辑 .blend（或等效源文件）、UV、材质、GLB | 身形约 1.65 m；+Y 向上、+Z 朝前；面部不换人；日常与披发为独立可控形态 |
| RIG-01 骨骼与表情 | 模型 → 根/髋/脊柱/颈/头/四肢/手指及发袖骨骼，blink/look/tired 形变 | 保留原画气质，动作不穿脸；骨骼蒙皮在源工程中可编辑 |
| ANIM-01 最小联合动作 | 绑定 → idle、breathe、blink、walk、stop、sit、recline、stand 剪辑 | 连续起坐、床枕接触、脚底固定；任何动作受伤势许可约束 |
| INTEGRATE-01 场景融合 | 合格 GLB、动画 → 本房间实际角色 | 同一状态适配器；有衣脸受光和屏风遮挡；实际设备运行后记录差异 |

预算建议而非实测：LOD0 不超过 60k 三角形、LOD1 不超过 25k、常规贴图 2K；服装/头发透明层优先控制叠加。预算最终以手机实际表现调整。

`character-manifest.json` 将这些资源和动画明确标记为 missing。临时代理不得作为正式人物验收，也不得以代理的简单旋转宣称呼吸、眨眼、坐卧过渡已完成。
