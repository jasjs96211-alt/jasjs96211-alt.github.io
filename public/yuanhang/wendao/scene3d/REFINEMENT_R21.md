# 寝居 R2.1：人物可读性与材质细化

2026-10-21，根据用户实际观看 R2 的反馈调整。只修改寝居样板，不扩展区域，不修改正式游戏系统，不制作人物资产。

- 屏风从主活动区右移、缩窄并降低，药柜前不再被屏风横挡；碰撞范围同步更新。
- 每 0.1 秒从当前镜头向人物头部、躯干及左右侧取样；命中的屏风、床帘、床柱、梁和前景案几暂时降至 12% 不透明度，离开遮挡后恢复。保留深度测试，淡化时关闭该物件阴影和深度写入，避免透明物仍压住人物。只影响演出，不改人物位置或业务状态。
- 四类 128px 可重复程序纹理：木纹、织物、纸面、灰泥；使用粗糙度与轻微凹凸区别表面。不是摄影扫描材质，也不声称达到影视写实品质。
- 家具边缘做细倒角，床围减薄；被褥加入细小褶皱与翻折，窗边灯具补齐支架；书案加书册、笔、牙板，药柜加罐与拉环，榻边加叠巾。
- 米灰墙面、棕木与灰绿织物替代大面积青绿色块。夜晚降低环境填光，月光来自窗外，暖灯保留局部衰减，两盏灯亮度有主次。
- 原三个镜头、四时光照、占位角色和六类行动保留。单文件失败时隐藏静态图片，只报告三维启动错误。

验证：17 项场景相关测试通过，包含屏风淡化与恢复、药柜视线、全路径避障、材质确定性和原场景回归。实际画面、夜景效果与手机 FPS 仍待用户设备检查；当前远程浏览器此前无法建立 WebGL 上下文，不把这些 CPU 检查当成视觉验收。
