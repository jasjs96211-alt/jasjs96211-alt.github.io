## 复现与原因

在隔离本机入口 `http://127.0.0.1:5174/yuanhang/index.html` 进入问道 → 陪伴修炼 → 去找姐姐，寝居文字为「安静休息」，人物仍为站姿。

事实链为 engine → LifeProjection → world → companion → motion。LifePresentation 的桥只接收新事件，CG 适配器不实际绘制姿态；首次进入也只建立基线。motion 的投影分支只处理阅读与有权限的疗养 CG，其余回退普通立绘，遗漏 rest。

## 修复

- 依据当前投影持续选择休息姿态，不依赖新事件或动画开关。健康、清醒的 rest 使用已有坐姿调息静帧；包括初始化的安静休息和 study 子事件的 rest 活动。
- 疗养 CG 仍需原有真实伤势权限，不增加解锁或业务收益。睡眠、伤病、疲劳需要卧姿而无合法素材时显示缺图提示，不以健康坐姿或站姿冒充。
- 坐姿加载失败不回退站姿；重试会重新加载。异地仍不显示人物，阅读仍使用阅读静帧。
- 更新 motion 脚本 URL 与离线缓存版本。无依赖、资产、存档结构或结算改动。
