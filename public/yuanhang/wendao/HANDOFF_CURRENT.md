### 供下一位开发者直接接续的接口用法

```js
const bridge = createLifeSceneBridge(scene);
const source = createLedgerSceneSource(bridge);
source.update({ledger, snapshot, live:false}); // 首次及后台恢复只建立基线
bridge.resume(); // 原上层控制器明确启用，不能自动恢复已取消任务
source.update({ledger:newLedger, snapshot:newSnapshot, live:true}); // 仅本次新事件
```

快照必须由权威系统提供world、state、sisterSleeping、permittedPoses；禁止从台账文案推断可以起身。每个source对应一个新bridge，sequence为该实例递增。隐藏时仍调用原bridge.setVisible(false)，恢复先基线；不要把历史纪事交给实时动作补播。
