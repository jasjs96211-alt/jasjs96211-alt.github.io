# 远航·问道：第一阶段增量更新 v1.1 （2026-10-15）

## 使用前
1. **先去原来有真实数据的入口导出「完整备份」JSON**。切勿先删除旧站、清理Safari数据、覆盖正在使用的电脑/手机数据。
2. 此ZIP是**源代码更新包**，不会自动替换线上 GitHub Pages。升级前请保留旧源码备份。部署后网页强刷/重启PWA以更新Service Worker缓存；保留同一个网址可维持同源localStorage。
3. 本地运行：Windows已安装Node.js 22及更新版后可双击 `yuanhang/start-windows.cmd`，浏览器打开 `http://127.0.0.1:8765`。本地与线上仍然是两个不同的存储来源，需JSON迁移或登录云端。

## 请注意：仍未被验证的部分
- **不能直接保证电脑+手机已同步**：必须两端分别登录**同一邮箱**，先分别导出备份，开启同步，检查“已同步”提示。用户账号/Supabase实际库和真实iPhone没有连通测试；邮箱验证配置若此前失败，本次代码不能凭空消除后端配置问题。
- **真正AI聊天尚未接通**：需要用户自己持有的模型API授权、服务端配置并启动聊天代理。Windows本机可用`wendao/server/launcher.mjs`启动代理；iPhone只能用另部署、带认证与用户隔离的HTTPS服务端。本ZIP不含模型密钥，也不宣称接通ChatGPT订阅。
- **立绘新增两档为状态框架而非独立新画作**。个人导入的图片依旧仅存此设备IndexedDB，跨设备请用“导出完整备份（含图片）”进行迁移。
- **同步合并不是跨设备专注计时的实时共享**：任何时刻应只有一个主要设备承担清醒计时，切设备前先保存、在新设备核对起床/午休状态，避免重复监管。
