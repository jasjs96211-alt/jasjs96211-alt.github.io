## 当前结构与数据

- `index.html`：独立 HTML/CSS/JavaScript，总览、日历、任务、专注、屏幕时间、数据与备份。
- `sw.js`：仅缓存远航静态资源；网络优先，离线回退，不缓存 API 或用户数据。
- `manifest.webmanifest`、`icon.svg`：应用安装信息和图标。
- 原存储键 `sisu_2027_study_workbench_v1` 保持不变，包含 events、sessions、screen；可选 focusTimer；V3.2 新增可选 usageSessions、usageImportedAt。
- events 新增可选 completedAt，老记录不伪造完成日期。学习统计不等于知识掌握度。
- 导入接受原版 JSON；逐项校验日期、类型、数值与唯一 ID。导入前保存一份 `sisu_2027_study_workbench_v1_before_import`，设置中可导出恢复。
- 导入成功时结束当前计时，不自动运行其他设备备份里的计时任务。写入失败时保持原数据。
- 暂停 Supabase：不加载登录或同步代码，不发起请求，不删除旧云配置或远端数据；历史代码可从 Git 恢复。

- 读取格式：`三角洲行动｜2026-10-11T12:45:00+08:00｜1分钟`；也接受半角竖线、空格、BOM、CRLF、小数点或小数逗号。开始文件 `yuanhang-delta-start.txt` 不符合记录格式，不导入。

## 2026-10-11 · 快捷指令链接接入 V3.3

- 在 V3.2 文件导入基础上支持 `https://jasjs96211-alt.github.io/yuanhang/#usage=<UTF-8 Base64>`，只接收一条本次记录，链接最长 4096 字符。多条历史记录仍选 TXT 文件导入。
- 网页加载或同一标签页 hashchange 时读取，立即用 replaceState 清除当前地址的片段，再展示游戏名、北京时间、分钟数预览。必须点击确认才写入；取消、解码错误、超长、未来记录不修改数据。
- Base64 仅用于传输格式，不是加密，也不认证来源；不能信任外部链接自动写入本机历史。使用 fragment 而非查询参数，应用不把内容发往服务端。浏览器仍可能保留最初导航痕迹，勿把含记录的原始链接当作秘密存储。
- 原有追加 TXT 和「显示结果」保留；用户可在其后添加三步：Base64 编码（输入原本次记录文本、换行无）→ URL（固定前缀 + 编码结果变量）→ 打开 URL。
- 将打开网页，不是静默后台同步。页面内折叠帮助和复制前缀按钮已提供。提醒用户使用原来存数据的同一浏览器；Safari / 默认其他浏览器 / 主屏幕应用的存储环境未必相同，不自动合并。
- 链接和 TXT 共用预览、确认保存、去重与排除逻辑。收到链接会取消尚未完成的文件读取，避免旧异步结果覆盖新预览。
- 32 项 Node 行为测试通过；构建、语法和 diff 检查通过。新增链接首次加载/同页接收、Unicode/URL 编码、重复打开、取消、异常、存储失败测试。iPhone 端新增三个操作及默认浏览器跳转尚待用户真机验证，不宣称已经端到端实测。
