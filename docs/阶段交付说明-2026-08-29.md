# 阶段交付说明｜2026-08-29

## 交付定位

本阶段完成了从“单一剧本杀网站”到“侨批项目总站”的第一版升级。重点是建立可继续生长的信息架构、内容边界和公开入口，而不是用未经核验的材料填满页面。

## 可见成果

- 新总站首页与九个内容方向；
- 17 条有来源关系的首批公开内容，其中档案索引条目内含 68 条 QP 元数据记录；
- 仅检索公开内容的全站搜索与栏目筛选；
- 基础侨路地图和“侨批历史 / 我们的研究”双轨时间轴；
- 《银信烽火》成果档案页和完整 Beta 体验入口；
- 桌面端与手机端响应式页面；
- 结构化内容、内容校验和 Obsidian 草稿导入流程；
- Campus Vault 首轮扫描与接入：档案索引、阿批 IP 概念、视频技术信息与来源证据等级；
- CloudBase 原部署配置与 Git 回滚点。

## 数据边界

- 侨批原件、人物、日期、地址、批文内容均未自行补写；68 条图像索引明确标为“待人工核验”。
- 公开的是档案索引元数据，不是已核验馆藏档案；一条 1923 年菲律宾线索仍保持草稿并从前台产物隔离。
- 视频入口、4 分 55.78 秒技术信息和“省（区域）级二等奖（银奖）”均附材料记载说明；正式证书/公示待补。
- 联系方式、学号、内部申请表与未授权采访不进入公开内容。

## 发布状态

本交付已在本地完成构建验证，但尚未发布到腾讯云。原线上 Beta 保持不变。完成项目账号授权后，可在项目根目录运行 `npm run deploy`；部署前仍会自动执行内容校验和 Vite 构建。
